# 3D Talking Assistant (V1) - She Care App

A lightweight 3D animated assistant for the She Care app featuring a talking cat character with Text-to-Speech capabilities.

## Overview

This is **NOT** a chatbot and **NOT** an LLM. The assistant only speaks predefined, rule-based messages generated by the application.

## Features

- **3D Cat Character** - Animated GLB model with idle and talking states
- **Text-to-Speech** - Native TTS (Android: TextToSpeech, iOS: AVSpeechSynthesizer)
- **Lip Sync** - Jaw-based mouth animation synchronized with speech
- **Gestures** - Random hand/head/tail gestures while talking
- **State Machine** - IDLE → TALKING transitions with smooth blending
- **Rule Engine** - Predefined response categories for women's health events
- **Speech Queue** - Sequential message playback with queuing support
- **Floating UI** - Bottom-right assistant with speech bubble and tap/long-press interactions

```
│   ├── GestureController.ts      # Gesture management and randomization

```

## Character States

### IDLE (Default)
- Breathing animation
- Blinking (every 3-8 seconds)
- Tail sway (every 2-5 seconds)
- Subtle head movement (every 6-10 seconds)

### THINKING (Optional)
- Brief transition state before speaking

### TALKING
- Mouth animation (6-8 movements/second)
- Random gestures every 2-4 seconds
- Smooth blend back to IDLE after speech

## Usage

```typescript
import { AssistantManager } from './src/assistant/AssistantManager';

// Initialize and show assistant
AssistantManager.getInstance().show();

// Speak a message
AssistantManager.getInstance().speak("Your next period is expected in three days.");

// Queue multiple messages
AssistantManager.getInstance().queue("First message");
AssistantManager.getInstance().queue("Second message");

// Hide assistant
AssistantManager.getInstance().hide();
```

## Trigger Events

The assistant speaks on important events only:
- App opened
- Prediction updated
- Period logged
- Medication reminder
- Achievement unlocked
- Cycle completed

## Performance Targets

- **60 FPS** consistent frame rate
- Model loads once, reused across sessions
- No renderer recreation
- Proper resource disposal
- Animation blending for smooth transitions
- Memory leak prevention

## Platform-Specific Notes

### Android
- Uses `android.speech.tts.TextToSpeech`
- Requires TTS engine installed (Google TTS recommended)

### iOS
- Uses `AVSpeechSynthesizer`
- Works out of the box
